# CODE PREDATORS — X-Ray to Finding Prototype
## 🌐 Live Website

[Visit the Website](https://your-website-link.com)

## Overview

**CODE PREDATORS** is a hackathon prototype demonstrating an AI-assisted X-ray analysis workflow.

The prototype accepts an X-ray image, identifies the likely body part, routes it to a specialized model, detects a potential abnormality, localizes the suspected region, and generates a preliminary finding for professional review.

## Important

This is a **hackathon UI/prototype** created to demonstrate the intended X-ray analysis workflow.

* The current abnormality findings and confidence values are **simulated for demonstration purposes**.
* The current browser-based body-part routing uses simple image geometry as a **deterministic demonstration**, not a trained medical AI model.
* Because of this, the current prototype may show an incorrect abnormality or suspected location for an uploaded X-ray.
* **After the complete creation, training, validation, and integration of the official ML models, the system is intended to analyze the actual X-ray image and produce real image-based findings instead of simulated results.**
* **Our development goal is to achieve approximately 99.9% accuracy after the complete ML system has been developed, trained, validated, and optimized.**
* The completed system will be designed to accurately identify potential abnormalities and their locations based on the actual X-ray.
* The final system will be intended as **clinical decision support**, with professional medical review remaining an essential part of the workflow.
* The current prototype is **not a validated medical AI system** and must not be used for medical diagnosis or treatment.

## How the Current Prototype Works

The current browser-only version uses simple image geometry to demonstrate body-part routing.

The detection and finding outputs are **simulated** rather than generated by trained medical AI models.

This approach allows the team to demonstrate the intended product workflow without requiring a trained medical imaging model or inference server.

## Production Upgrade

The prototype can be upgraded into a real AI-assisted medical-imaging system by replacing the simulated components with validated models.

### 1. Body-Part Classifier

Train a 3-class image classifier:

```text
X-ray
  ↓
Body-Part Classifier
  ├── Dental
  ├── Chest
  └── Forearm
```

### 2. Specialized Models

Each body part can have its own dedicated model.

```text
Dental → Dental Abnormality Model
Chest → Chest Abnormality Model
Forearm → Fracture Detection Model
```

This allows each model to be optimized for the anatomy and abnormalities relevant to that body part.

### 3. Abnormality Localization

Instead of displaying a simulated region, production inference should use techniques such as:

* Object detection
* Image segmentation
* Bounding-box localization
* Heatmaps
* Grad-CAM / explainability methods

### 4. FastAPI Inference Backend

The browser frontend can send the X-ray to a backend:

```text
React Frontend
      ↓
FastAPI
      ↓
Body-Part Classifier
      ↓
Specialized Model
      ↓
Localization
      ↓
Finding Generator
      ↓
Result → React
```

### 5. Case Storage

Supabase/PostgreSQL can store:

* Case ID
* Uploaded image reference
* Body part
* Model used
* Detection result
* Localization information
* Confidence score
* Timestamp
* Review status

## Project Goal

The goal of **CODE PREDATORS** is to demonstrate how an AI-assisted X-ray workflow could automatically route different types of X-rays to specialized analysis pipelines and surface potentially important regions for professional review.

The current version focuses on demonstrating the **end-to-end concept and user experience**, while the production roadmap replaces the simulated components with trained, validated medical AI models.
